# Code

Private scripts and settings for the Southwest Fire Danger site.
The workflows in `swcc-fire-danger/fd` copy `scripts/` and `data/` from here before each run.

- `scripts/` — FEMS pulls, FDRA history, website data build, access sync
- `data/` — FDRA list (`r3_fdra.csv`), station lists, FDRA percentile history
